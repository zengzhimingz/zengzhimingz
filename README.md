## 🚀 Featured Projects

### 🌌 [马后炮 · Mahoupao](https://github.com/zengzhimingz/mahoupao)

**记录当时的判断，看见后来的答案。**

记下工期预估，到期核对实际用时；通过个人 3D 星图、历史记录与偏差统计，为下一次估时提供依据。支持手动记录，AI 与飞书可按需配置。

### 🖥️ [Mosaic Desk](https://github.com/zengzhimingz/wow-super-desktop)

**AI-powered desktop workspace.**

围绕桌面工作场景构建 AI 工作空间，探索更直观的应用与信息组织体验。

### 📊 [OmniTable · AI Diagram](https://github.com/zengzhimingz/omnitable-ai-diagram)

**让专业图表更容易生成，也更容易修改。**

AI 驱动的五类专业图表生成与可视化编辑工作台。

### 🎙️ [听懂 AI](https://github.com/zengzhimingz/tingdong-ai)

**把论文和长文，变成真正听得懂的双人播客。**

用对话形式重新组织知识内容，探索阅读之外的理解方式。

### 👗 [LUMERA](https://github.com/zengzhimingz/lumera)

**面向服饰电商的 AI 视觉制作工作台。**
